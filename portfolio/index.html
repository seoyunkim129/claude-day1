ABOUT

문제 정의부터 결과 전달까지 전 과정을 직접 설계합니다.

데이터가 사람에게 닿는 지점까지를 하나의 설계 대상으로 봅니다. 수집·적재·정합성 검증·전달을 끊지 않고 잇는 일에 관심이 있습니다.

회귀분석과 클러스터링으로 인사이트를 도출하는 분석 작업에서 시작해, ABSA 모델링과 논문 작성까지 진행했습니다. 문장 안의 속성별 감성을 분리하는 구조를 직접 설계하고 두 사전학습 모델의 입력 구조 차이가 성능에 미치는 영향을 실험으로 검증했습니다.

이후 실무에서는 분석 이전 단계인 데이터가 만들어지는 과정을 맡았습니다. 16개 스키마·319개 테이블 규모의 데이터 플랫폼에서 수기 적재 파이프라인을 운영하고, 집계 규칙이 걸러내고 있던 연 단위 매출을 복원했으며, 현업의 업무 규칙을 인터뷰로 수집해 검증 가능한 데이터 모델로 옮겼습니다.

공통점은 숫자가 맞는지 확인하는 기준을 먼저 세우는 것입니다. 가설이 기각되면 데이터 탓 대신 구조적 편향을 추적하고, 설명되지 않는 차이는 억지로 맞추지 않고 명시해 남깁니다.

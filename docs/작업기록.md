## 2026-10-14 — 협업 지표 수집기 + 플러그인 하네스 첫 버전

- **하려던 것**: 프로젝트마다 손으로 하던 "결정·검증·AI 오류 기록"을 재사용 가능한 플러그인으로 묶고, 전체 프로젝트에서 AI에 얼마나 개입했는지 숫자로 만들려고 했다.
- **한 것**:
  - `collab_metrics.py`: `~/.claude/projects` 세션 원본과 각 프로젝트의 `docs/포트폴리오-기록.md`를 읽어 지표를 만든다
  - `llm_classify.py`: 프롬프트를 바로잡기/되묻기/그 외로 Claude(`claude -p`)가 분류한다
  - `heuristic_eval.py`: 정답표를 만들고 분류 정밀도를 잰다
  - `collab_dashboard.py`: 단일 파일 대시보드
  - 플러그인: SessionEnd 훅(`session_log.py`), 스킬 3개(new-project, record, collab-report), 마켓플레이스 정의
- **숫자** (2026-10-14 집계):
  - 세션 113개, 고유 프롬프트 831건, 도구 호출 약 5,300회, 협업 시간 96.6시간
  - 중복 제거 전에는 프롬프트 2,148건으로 세지고 있었다 (세션 이어하기 시 이전 대화 복사)
  - 분류 정확도(정답표 60건, 라벨은 Claude 임시값): 키워드 55% → Claude 분류 v2 69% → v3 72%
  - 바로잡기 정밀도 45% → 61%, 되묻기 정밀도 40% → 53%
- **검증**:
  - 훅: 임시 폴더에 xai 세션을 두 번 넣어 한 줄만 남는지(같은 세션 덮어쓰기) 확인. 빈 입력에도 종료코드 0
  - `claude plugin validate`로 플러그인·마켓플레이스 검사 통과
  - 대시보드: 콘솔 오류 0, 데스크톱·모바일(375px)에서 가로 넘침 없음, 팔레트 색각 검사 통과
- **막힌 것 / 남은 한계**:
  - 정답표 라벨을 사용자가 아직 직접 붙이지 않았다. 지금 정밀도는 "Claude가 Claude를 채점한" 값이라 본인 재검수가 필요하다
  - v3 프롬프트를 같은 60건을 보며 고쳤으므로 과적합 가능성이 있다. 새 표본(다른 seed)으로 다시 재야 한다
  - 플러그인은 아직 설치하지 않았다 (설치하면 모든 세션에 훅이 걸리므로 사용자 확인 필요)

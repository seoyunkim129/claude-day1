# 새 프로젝트 셋업

이 스킬은 현재 작업 폴더에 세 파일을 만든다. 템플릿은 이 스킬 폴더의 `templates/`에 있다.

## 순서

1. **이미 있는지 먼저 본다.** `CLAUDE.md`, `docs/작업기록.md`, `docs/포트폴리오-기록.md` 중 있는 게 있으면 덮어쓰지 말고, 무엇이 있는지 알려주고 빠진 것만 만들지 묻는다. 기존 CLAUDE.md가 있으면 템플릿의 "기록 규칙" 절만 덧붙이는 안을 제시한다.
2. **네 가지를 한 번에 묻는다** (모르는 건 비워도 된다고 말한다):
   - 프로젝트 이름
   - 한 줄 설명 — 누구의 어떤 문제를 푸는가
   - 기간 (시작일 ~ 종료일, 실제 날짜로)
   - 용도 — 과제 / 포트폴리오 / 업무 / 둘 다, 팀이면 인원
3. 템플릿의 `{{...}}` 자리를 답으로 채워 파일을 만든다. 답이 없는 자리는 `(미정)`으로 둔다. "이 프로젝트에만 해당하는 규칙" 절은 대화에서 나온 게 있으면 채우고, 없으면 절째로 지운다.
4. `docs/작업기록.md` 맨 아래에 첫 항목을 덧붙인다: 오늘 날짜, "프로젝트 시작 · 기록 체계 셋업", 정한 범위.
5. 끝나면 사용자에게 세 가지를 알려준다:
   - 앞으로 단계가 끝날 때마다 기록이 자동으로 쌓인다는 것 (`/collab-harness:record`)
   - 세션이 끝나면 `docs/세션로그.md`에 숫자가 자동으로 남는다는 것 (훅, 이 폴더처럼 `docs/작업기록.md`가 있을 때만)
   - 전체 프로젝트 지표는 `/collab-harness:collab-report`로 볼 수 있다는 것

## 지키는 것

- 비밀값(.env, 토큰)은 어떤 파일에도 쓰지 않는다.
- 사용자가 준 표현을 그대로 쓴다. 한 줄 설명을 멋있게 다시 쓰지 않는다.
